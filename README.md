# yt-dlp-GUI-YTDownloadly
A simple plug-and-play YouTube downloader. 😊 Made with a lot of love! 💖

Step 1:

Unzip the files using 7zip, WinRAR, or the default windows unzipping tool.

<img width="711" height="529" alt="image" src="https://github.com/user-attachments/assets/6fb31683-a45f-498e-9115-7e2a7b265aae" />

Step 2:

The software is in the main subfolder of the dist folder. It is named 'YTDownloadly.exe'

<img width="619" height="56" alt="image" src="https://github.com/user-attachments/assets/3847e38f-cea0-4c3c-8ed2-ca4dace397bb" />

Step 3:

Windows might say the file is malware but this is normal for any .exe with a non-popular or starting out publisher. You can see the source code yourself, there's no malware.

Step 4:

Click on it and use it! I hope you like this little project! 😊

<img width="1365" height="706" alt="image" src="https://github.com/user-attachments/assets/86af8c7f-c784-4602-9418-de5608f2b84c" />

Note:
This is a yt-dlp GUI wrapper that has ffmpeg, ffprobe, and deno built in. So it isn't required to install any other software
